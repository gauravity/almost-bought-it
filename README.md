# Almost Bought It

A tongue-in-cheek, impossible-to-win 16-bit top-down RPG about Josh trying to save for a MacBook Pro before Week 40 arrives — while juggling WordPress PM tickets, WoW raids, Modular Mail (`0` paying customers, `£0.00 MRR`), AI model-hopping, rotating his tiny rectangle office, Hin, Milo, HotUKDeals drops, Ormskirk runs, and "£0 free" Antibes trips.

## Play Locally

```bash
npm install
npm run dev
```

## Build & Test

```bash
npm test
npm run build
```

## GitHub Pages Deployment

Pushing to `main` automatically runs tests, builds `dist/`, and deploys to GitHub Pages via `.github/workflows/deploy.yml` (set **Settings → Pages → Source** to **GitHub Actions**).
